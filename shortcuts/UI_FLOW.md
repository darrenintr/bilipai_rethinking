## 颜色方案 (Street Redesign)

```swift
- 主色调：PaladalaTheme.biliPink  (#FB7299)
- 文字：PaladalaTheme.ink         (黑色)
- 次要文字：PaladalaTheme.mutedInk  (灰色)
- 背景：PaladalaTheme.paper       (白色)
- 画布：PaladalaTheme.canvas      (浅灰)
- 边框：PaladalaTheme.borderWidth (2pt)
- 阴影：hard shadow (offset 3-4pt)
```

## 交互说明

### 引导界面交互

1. **下载快捷指令**
   - 点击后：打开 Safari 或 Shortcuts App
   - URL：`https://github.com/.../安装Paladala.shortcut`
   - 用户在外部完成安装

2. **我已安装**
   - 点击后：
     - 设置 `hasInstalledShortcut = true`
     - 关闭引导界面
     - 返回「关于」页面

3. **暂时跳过**
   - 点击后：关闭引导界面
   - 下次点击「检查更新」时会再次显示

### 更新界面交互

1. **检查更新**
   - 首先检查快捷指令是否已安装
   - 未安装：显示引导界面
   - 已安装：调用 GitHub API

2. **一键安装**
   - 点击后：
     - 调用 `shortcuts://x-callback-url/...`
     - 切换到 Shortcuts App
     - 快捷指令自动运行
     - 完成后调用 SideStore

3. **设置快捷指令**（错误恢复）
   - 仅在出现快捷指令相关错误时显示
   - 点击后：显示引导界面

## 状态消息

| 状态 | 消息 | 图标 |
|------|------|------|
| 检查中 | 正在检查更新... | ⏳ ProgressView |
| 已是最新 | 已是最新版本 · v0.5.1 | ✅ checkmark.circle.fill |
| 有更新 | 有可用更新 · v0.5.2 | ⬆️ arrow.up.circle.fill |
| 开发构建 | 开发构建 | 🔨 hammer.fill |
| 准备中 | 准备中 | ⏳ ProgressView |
| 已完成 | 已调用快捷指令，请在快捷指令中完成安装 | ✅ checkmark.circle.fill |
| 错误 | 请先安装快捷指令 / 网络请求失败 | ⚠️ exclamationmark.triangle.fill |

## 字体规范

```swift
- 大标题：.system(size: 24, weight: .black, design: .monospaced)
- 卡片标题：.system(size: 15, weight: .bold, design: .monospaced)
- 正文：.system(size: 13, weight: .semibold/.medium, design: .default)
- 小字：.system(size: 11, weight: .medium, design: .monospaced)
- 说明：.system(size: 10, weight: .medium, design: .monospaced)
```

## 动画

- 引导界面：`.sheet` 模态动画（从底部滑入）
- 状态消息：淡入淡出（`.opacity`）
- 按钮反馈：`.buttonStyle(.plain)` + 触觉反馈
- Toast 提示：从底部滑入 + 淡出
