# Paladala 快捷指令集成测试清单

## 前置条件

- [ ] iOS 设备（iPhone 或 iPad，iOS 15+）
- [ ] 已安装 Shortcuts App（系统自带）
- [ ] 已安装 SideStore、AltStore 或 Feather（任一侧载工具）
- [ ] 已配置 GitHub 账号并可以访问 repository releases

## 测试步骤

### 1. 构建快捷指令

- [ ] 在 iOS 设备上打开 Shortcuts App
- [ ] 按照 `build-shortcut.sh` 中的步骤创建快捷指令
- [ ] 确认快捷指令名称为：**安装Paladala**（完全匹配）
- [ ] 配置允许从其他 App 运行
- [ ] 导出 .shortcut 文件到项目的 `shortcuts/` 目录

### 2. 测试快捷指令独立运行

- [ ] 在 Shortcuts App 中手动运行快捷指令
- [ ] 输入测试 IPA URL：
  ```
  https://github.com/darrenintr/pure-bilibili-rethinking/releases/download/v0.5.1/Paladala-unsigned.ipa
  ```
- [ ] 验证快捷指令是否：
  - [ ] 显示下载进度
  - [ ] 成功下载 IPA 文件
  - [ ] 保存到 iCloud Drive/Shortcuts/Paladala/
  - [ ] 自动打开 SideStore 并传递文件路径
  - [ ] SideStore 显示安装确认界面

### 3. 编译并安装 Paladala App

- [ ] 在 Xcode 中打开 `ios/Paladala.xcodeproj`
- [ ] 确认新文件已添加到项目：
  - [ ] `ShortcutManager.swift`
- [ ] 编译项目（Product → Build）
- [ ] 检查编译错误或警告
- [ ] 安装 App 到测试设备

### 4. 测试首次启动流程

- [ ] 删除 App 并重新安装（模拟首次启动）
- [ ] 打开 App，进入「我的」→「关于」
- [ ] 点击「检查更新」
- [ ] 验证是否显示快捷指令安装引导界面
- [ ] 检查引导界面 UI：
  - [ ] 标题和说明文字清晰
  - [ ] 三个步骤说明易懂
  - [ ] 按钮样式符合 Street Redesign 主题
- [ ] 点击「下载快捷指令」按钮
- [ ] 验证是否跳转到正确位置（Safari 或 Shortcuts App）

### 5. 测试快捷指令安装确认

- [ ] 在引导界面点击「我已安装」
- [ ] 验证界面关闭
- [ ] 重新打开「关于」页面
- [ ] 再次点击「检查更新」
- [ ] 验证不再显示引导界面（已记住安装状态）

### 6. 测试完整更新流程

- [ ] 在「关于」页面点击「检查更新」
- [ ] 等待检查完成
- [ ] 如果有更新可用，点击「一键安装」按钮
- [ ] 验证：
  - [ ] App 调用快捷指令（自动跳转到 Shortcuts App）
  - [ ] 快捷指令开始下载 IPA
  - [ ] 下载完成后自动调用 SideStore
  - [ ] SideStore 显示安装确认
  - [ ] 安装成功

### 7. 测试错误处理

#### 7.1 快捷指令未安装
- [ ] 清除 UserDefaults：设置 → Paladala → 重置数据
- [ ] 删除已安装的快捷指令
- [ ] 在 App 中点击「检查更新」
- [ ] 验证显示引导界面
- [ ] 点击「暂时跳过」
- [ ] 再次点击「检查更新」
- [ ] 验证再次显示引导界面

#### 7.2 网络错误
- [ ] 关闭网络连接
- [ ] 点击「检查更新」
- [ ] 验证显示网络错误提示

#### 7.3 无新版本
- [ ] 使用最新版本的 App
- [ ] 点击「检查更新」
- [ ] 验证显示「已是最新版本」

#### 7.4 SideStore 未安装
- [ ] 卸载 SideStore
- [ ] 运行完整更新流程
- [ ] 验证快捷指令下载成功后：
  - [ ] 尝试打开 SideStore URL scheme 失败
  - [ ] 显示友好的错误提示或回退方案

### 8. 测试 UI/UX

- [ ] 引导界面的视觉风格符合 Street Redesign
- [ ] 按钮有正确的 hard shadow
- [ ] 颜色使用 `PaladalaTheme.biliPink` 和 `PaladalaTheme.ink`
- [ ] 字体使用等宽字体（monospaced）
- [ ] 中文文案清晰易懂
- [ ] 按钮点击有适当的触觉反馈
- [ ] 状态消息实时更新

### 9. 测试持久化

- [ ] 安装快捷指令并标记「我已安装」
- [ ] 完全关闭 App（从后台清除）
- [ ] 重新打开 App
- [ ] 点击「检查更新」
- [ ] 验证不再显示引导界面（状态已持久化）

### 10. 回归测试

- [ ] 原有的更新检查功能正常工作
- [ ] 构建信息显示正确
- [ ] 特别辨识号可以复制
- [ ] 其他「关于」页面功能未受影响

## 已知限制

- 快捷指令需要用户手动安装一次
- 快捷指令在后台运行时，用户会短暂看到 Shortcuts App
- 下载大文件时，iOS 可能会限制后台下载时间
- iCloud Drive 需要有足够的存储空间（至少 200MB）
