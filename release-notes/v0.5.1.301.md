un-ignore release-notes/*.md so the Plan C step can commit


Build 8bb98176 failed in the 'Extract clean release notes' step
with:

  The following paths are ignored by one of your .gitignore files:
  release-notes/v0.5.1.300.md

Root cause: .gitignore's blanket '*.md' rule (added for the docs
whitelisting scheme) is not specific enough — it caught the
release-notes markdown files the new CI step writes, and 'git add'
refused to stage them.

Two fixes:

* .gitignore — add a '!release-notes/' and '!release-notes/*.md'
  whitelist next to the existing docs whitelist so the files are
  intended git content. Comment explains why they're meant to be
  tracked (consumed by generate_apps_json.py at build time).

* ios-unsigned-ipa.yml — switch 'git add' to 'git add -f' as a
  safety net. If a future ignore-rule change accidentally re-blocks
  these files, the failure mode becomes an explicit 'git add -f'
  rejection rather than a silent skip-and-empty-commit; the intent
  is loud and obvious in the step log.
