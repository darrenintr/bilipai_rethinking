move FailableDecodable diag counter to file-scope enum


Swift does not allow `static var` (a stored property)
inside a generic type — only computed `static var` and
`static let` are legal on a generic struct. The v0.5.24
build 324 attempt failed with:

  error: static stored properties not supported in
         generic types
   at CommentPipeline.swift:962:36
  error: generic parameter 'T' could not be inferred
   at CommentPipeline.swift:784:9   (the call site)

The fix is a non-generic file-scope enum
(`FailableDecodableDiag`) that owns the
`failureCount` mutable storage. The generic
`FailableDecodable<T>` struct's `init(from:)` increments
`FailableDecodableDiag.failureCount` and the comment
fetch path resets it via
`FailableDecodableDiag.failureCount = 0`. Same
rate-limit contract (3 lines per fetch), just living
on a non-generic type. No behaviour change.
