declare AppQrcodePollResult.cookies fileprivate


Swift requires a method's access level to be at least as
restrictive as the most-restrictive type in its signature.
`static func cookies(fromCookieInfo:fromPollURL:response:)`
takes `[TvQrcodePollResponse.TvData.Cookie]?` — a private
nested type — so the method body lived at internal access
and the compiler refused to emit the binary, failing the
CI xcodebuild step with:

  error: method must be declared fileprivate because its
         parameter uses a private type

Make it fileprivate (its only caller is `appQrcodePoll`,
which lives in the same file). No behaviour change.
