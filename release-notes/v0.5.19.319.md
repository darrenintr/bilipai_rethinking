use non-mutating String replacement in userAgent


The v0.5.19 build failed to compile because DeviceInfo.userAgent
called `iosVersion.replace(".", with: "_")` on a `let`
constant — `String.replace` is a mutating method and Swift
rejects the call. Switched to the non-mutating
`replacingOccurrences(of:with:)` form, hoisted the underscored
iOS version into a separate `let` so the format string can
still interpolate it. No behavior change otherwise.
