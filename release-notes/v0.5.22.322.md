pass dumpRawBody/dumpTag before anonymousRequest


Swift requires labeled arguments to follow the declaration
order in the callee. `get<T>` declares
`dumpRawBody, dumpTag, anonymousRequest` in that order, so
the new `AnonymousMainEndpoint.fetchPage` call had to put
`dumpRawBody: true, dumpTag: "comments-raw-anon-main"`
before `anonymousRequest: true`. The v0.5.22 build 322
attempt failed with:

  error: argument 'dumpRawBody' must precede argument
         'anonymousRequest'

at CommentPipeline.swift:608:17. Reorder, push, CI
re-runs. No logic change.
