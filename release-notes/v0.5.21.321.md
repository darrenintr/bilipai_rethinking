drop plat / web_location / seek_rpid from WBI query


The v0.5.20 PiliNara-port build landed with the right
User-Agent (BiliDroid/2.0.1), the right x-bili-trace-id
header, and no WBI signature, but the server now returns
explicit -403 "访问权限不足" instead of the previous silent
gate. PiliNara's `lib/http/reply.dart` `ReplyHttp.replyList`
anonymous branch only sends four query items: `oid`, `type`,
`pagination_str`, and `mode`. Paladala was still sending
`plat=1`, `web_location=1315875`, and `seek_rpid=` from
the legacy web-client shape; on the Android-HD UA that
combination reads as iOS-web-pretending-to-be-android and
triggers the explicit -403. Drop the three extra params
to match PiliNara's anonymous request shape.
