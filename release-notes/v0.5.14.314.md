use file-level appKey/appBuild in app endpoint


CI #589 caught:

  error: value of type 'BilibiliAPIClient' has no member 'appBuild'
  error: value of type 'BilibiliAPIClient' has no member 'appKey'

`appKey` and `appBuild` are file-level constants in
`BilibiliAPIClient.swift` (the same way they were read by the
`recommendedVideos` / `appRecommendedVideos` callers before the
refactor). The new `AppSignedEndpoint` was reaching through
`apiClient.appBuild` / `apiClient.appKey` as if they were instance
properties — drop the `apiClient.` prefix to read the file-level
constants directly. `appBuild` also needed `private` dropped so the
pipeline (which lives in another file) can reach it.
